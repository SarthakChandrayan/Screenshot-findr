02

How it works

A small local web app: a Python backend indexes your screenshots, and a browser page searches them.

  1. watch

    Find screenshots

    Detects Pictures\Screenshots, OneDrive and Game Bar folders, then rescans every minute and only reads new or changed files.

  2. read

    Read the text

    Uses the OCR engine built into Windows, with Tesseract as a fallback. Images never leave the PC.

  3. index

    Make it searchable

    Text goes into SQLite FTS5 for instant word search, plus a local embedding model for search by meaning.

  4. organise

    Keep it tidy

    Rule-based tags, perceptual-hash duplicate detection and a weekly digest of forgotten screenshots.

Download

Free for Windows and macOS. No account, no cloud.

Get the app

  1. Download the zip below and extract it anywhere.
  2. Double-click ScreenshotFindr.exe. Your browser opens the search page.
  3. The first run reads all your screenshots, which takes a few minutes for a big folder.
ScreenshotFindr-windows.zip All releases

Windows may show "Windows protected your PC" because the app isn't code-signed. Click More info → Run anyway.

macOS

# Terminal, with Python 3.9+
git clone https://github.com/SarthakChandrayan/Screenshot-findr
cd Screenshot-findr
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[smart]"
python -m screenshot_findr

Finds your screenshot folder (Desktop or your custom location) and reads text with Apple's built-in Vision engine. No one-click Mac download yet.

Windows, from source

# PowerShell, with Python 3.9+
git clone https://github.com/SarthakChandrayan/Screenshot-findr
cd Screenshot-findr
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[smart]"
.venv\Scripts\python -m screenshot_findr

Weekly reminder: screenshot_findr reminder install. Terminal search: screenshot_findr search wifi.
